# Style catalog

Generated from `src/styles/global-style-catalog.ts` by `scripts/catalog-doc.mjs`; do not edit by hand. A fresh library is seeded with these 55 records in 9 capabilities. Existing libraries are never overwritten.

## How the catalog fits together

- **Capabilities** group styles. Every capability here is *combinable*: a project can select several of its styles. Switch a capability to *Pick one* in Capabilities → Rename when its styles are alternatives.
- **Required styles** always load with the style that requires them, transitively. A style lists only direct requirements (at most 12). Format styles such as Draw.io and Mermaid are selected per project, never required.
- **Skills** are referenced by installed name with a "(when …)" condition. Each style's SKILLS section says when to read a skill, the order, what it must not override and the fallback when it is missing. Nothing requires installing a skill.
- Each style's text uses the same sections: SCOPE, INPUTS, METHOD, DELIVERABLES, SKILLS, REQUIRED STYLES, VERIFICATION, REFERENCES.
